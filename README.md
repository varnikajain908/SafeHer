# SafeHer 🛡️

**A Women’s Safety Web Application**

SafeHer is a web development project designed to support women's safety through accessible safety features and emergency assistance tools.

## ✨ Features
- SOS emergency assistance
- Emergency contacts
- Safety tips
- User interface for safety-related tools

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript

## 🚀 Getting Started
1. Clone or download this repository.
2. Open `w.html` in your browser.
3. Allow location access if required for location-based features.

## 🎯 Project Goal
To explore how web technologies can help make safety tools more accessible and user-friendly.

## ⚠️ Disclaimer
SafeHer is a student project and should not be relied upon as a replacement for verified emergency services.
